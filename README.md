# 🚀 Proposals.ai

> **The Next-Gen AI-Powered Proposal Generator for Modern Freelancers.**

Proposals.ai is a state-of-the-art AI platform built for freelancers that analyzes any client job description and generates high-converting, professional cover letters and proposals in seconds.

---

## ✨ Core Features

* **🤖 Advanced AI Engine:** Powered by Google Gemini AI to generate accurate, highly relevant proposals.
* **🎯 Dynamic Tone & Style Selector:** Tailor pitch styles to match project requirements (e.g., *Professional & Direct*, *Short & Punchy*, *Deep Technical*, etc.).
* **⚡ Real-time Generation:** Generates instant proposal outputs with a single click.
* **📋 One-Click Copy:** Effortlessly copy generated proposals to submit directly on Upwork, Fiverr, or remote job boards.
* **📱 Mobile-First Glassmorphism UI:** Clean, responsive, modern interface designed to work seamlessly on both mobile devices and desktops.

---

## 🌟 Benefits & Perks

* **Saves Time:** Eliminates hours spent drafting pitches by generating tailored proposals in under 5 seconds.
* **Boosts Client Engagement:** Captures the client’s focus in the first two lines by addressing their core pain point directly, significantly raising reply rates.
* **Maximizes Efficiency:** Lets freelancers spend less time writing proposals and more time winning and managing client projects.
* **Freemium Growth Model:** Offers an extended free beta period so freelancers can integrate the tool seamlessly into their daily workflow.

---

## ⚙️ How It Works

1. **Paste Job Description:** Copy a client's job posting from Upwork, Fiverr, or any remote board and paste it into the Proposals.ai input box.
2. **Select Tone/Style:** Choose your preferred writing style (e.g., Professional, Short & Punchy, Solution-Focused).
3. **AI Analysis:** Our backend Gemini AI model analyzes the client's needs in-depth and drafts a unique, high-converting pitch.
4. **Copy & Submit:** Copy the generated proposal with a single click and submit it directly to your client!

---

## 🛠️ Tech Stack

* **Backend:** Python, Flask, Gunicorn
* **AI Integration:** Google Gemini API (`gemini-1.5-flash`)
* **Frontend:** HTML5, Tailwind CSS, JavaScript, Marked.js
* **Deployment:** Render Cloud Platform

---

## 🚀 Quick Start (Local Setup)

1. Clone the repository or download the code.
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Set your environment variables (in a `.env` file):
   ```env
   GOOGLE_API_KEY=your_gemini_api_key_here
   ```
4. Run the application:
   ```bash
   python app.py
   ```
